# Create a new filename with a timestamp

Create a new filename with a timestamp

## Usage

``` r
nf(filename, filepath = NULL, timestamp_format = "%Y-%m-%dT%H-%M-%S")
```

## Arguments

- filename:

  The filename.

- filepath:

  The path where the file should be saved.

- timestamp_format:

  The format for the timestamp

## Value

a timestamped filename including a path (if one is supplied)
